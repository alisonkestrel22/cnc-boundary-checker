CNC boundary check

Signing in lets you add, remove and replace projects. You need a GitHub account with access to , and a token from it:
  1. Open GitHub’s new token page.
  2. Under Repository access, choose Only select repositories and pick this repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it here.

The token is kept in this browser only. Use “Sign out” on shared computers.
